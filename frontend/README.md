# Frontend React — ébauche

Ce dossier contient l'ébauche du futur tableau de bord React (`src/App.js`
référence un composant `reseau-prediction` encore à développer, et le
`package.json` n'existe pas encore).

👉 **Pour la démonstration du prototype, utiliser le tableau de bord servi
directement par l'API** : lancer `uvicorn api.main:app --port 8000` puis ouvrir
<http://localhost:8000/dashboard>.

Le frontend React consommera la même API versionnée (`/api/v1/*`) lorsque le
projet passera en phase d'industrialisation.
